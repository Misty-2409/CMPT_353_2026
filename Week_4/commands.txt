week4 (typeS)
-------------------
npm install cors
npm install -D typescript ts-node @types/node @types/express
npm install -D @types/cors
npm pkg set type=module
npx tsc --init

Package			Why
cors			handles GET / POST / PUT / DELETE from localhs URL
typescript		Understand .ts
ts-node	Run 	.ts directly
@types/node		Node types
@types/express	Express types
type=module		modern module import / export
tsc --init		creates tsconfig.json

--------------------------------------
Compile and Run
--------------------------------------
**** without docker ****
--------------------------------------
--------------------------------------
1**If you want to run .js file
------------------------------
--> then go to tsconfig.json 
    and comment out dist
--> compile and create js version -->  npx tsc
--> check js creation --> dist/server.js
--> and then run js code --> node dist/server.js
------------------------------
2**If you want to run .ts file
------------------------------
--> compile and run -->  npx ts-node server.ts

--------------------------------------
**** with docker ****
--------------------------------------
1**If you want to run .js file
------------------------------
add the followings to your current docker (pre-week's docker)
--> COPY dist ./dist
--> CMD ["node", "dist/server.js"]
add the followings to your current docker-compose.yml (pre-week's docker)
volumes:
      - .:/app
      - /app/node_modules
      #import express from "express";    
    ## .ts to .js
    command: node dist/server.js
--------------------------------------
2**If you want to run .ts file
------------------------------
add the followings to your current docker (pre-week's docker)
--> CMD ["npx", "ts-node", "server.ts"]
add the followings to your current docker-compose.yml (pre-week's docker)
volumes:
      - .:/app
      - /app/node_modules
      #import express from "express";    
    ## .ts
    command: npx ts-node server.ts
