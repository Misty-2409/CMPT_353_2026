## What is React?
React is a JavaScript library for building user interfaces (UI)
Instead of:
- manually editing the DOM
- juggling getElementById
- worrying about updates
React says:
- Describe what the UI should look like, I’ll handle the how.

## Why Vite?
Vite is a project generator + dev server 
vite = fast frontend engine

Browsers do NOT understand:
- JSX (<h1>Hello</h1> in JS)
- TypeScript
- imports across hundreds of files
So we need a tool to:
- compile code
- serve it fast
- reload instantly
