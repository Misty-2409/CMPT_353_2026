------------------------------------
potential error
------------------------------------
if 3002 port is occupied by previous week's code.
--> check first
	--> from root project
		--> netstat -ano | findstr :3002
	--> if occupied thn following:
		--> taskkill /PID 13084 /F
------------------------------------
docker
------------------------------------
--> create frontend and backend dockerfiles like previous example (see commands.txt)
--> configure docker-compose.yml (uploaded on this repository)
--> run the commands
	--> docker compose down --rmi all
	--> docker compose up --build
--> create database by borwsing: http://localhost:3002/init
--> now access UI or your webpage at http://localhost:5173
