backend dockerfile 
------------------------------------

--> # Copy rest of backend code

------------------------------------
frontend dockerfile 
------------------------------------
create a new dockerfile like WEEK 4 and adjust the following changes
--> # Copy rest of frontend code
	  COPY . .
--> # Expose Vite dev server port
	  EXPOSE 5173
--> # Run Vite
	  CMD ["npm", "run", "dev", "--", "--host"]
------------------------------------
docker-compose.yml (detail in example uploaded)
------------------------------------
--> open yml file and add two instances of week 4 yml (frontend and backend)
	--> backend 
		--> adjust week 4 based on name/port
	--> frontend
		--> adjust week 4 based on name/port
		--> add the followings:
			environment:
			- VITE_API_URL=http://host.docker.internal:3002
			command: npm run dev -- --host 0.0.0.0
--> docker compose down --rmi all
--> docker compose up
