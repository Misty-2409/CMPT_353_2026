npx create-next-app@latest next-crud

	When prompts appear:
		Would you like to use the recommended Next.js defaults? » No, customize settings
		TypeScript? → Yes
		ESLint? → Yes
		App Router? → Yes
		Tailwind? → No (keep simple)
		src directory? → Yes
		Import alias? → No
		React Compiler → No

cd next-crud

compile and run:
	production mode
		npm run build
		npm start
	development mode
		npm run dev

	check --> http://localhost:3000 --> This is React, but powered by Next.js.

	folder structure
		src/app/
			layout.tsx
			page.tsx
	here
		page.tsx = homepage
		layout.tsx = wrapper
		folder name = route

Create new route: (FRONTEND)
	src/app/users/page.tsx
		add your TypeScript to page.tsx
			export default function UsersPage() {
					return <h1>Users Page</h1>;
				}
		check --> http://localhost:3000/users 
	No React Router needed.
	Folder name = URL
