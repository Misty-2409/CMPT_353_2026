******************************** WEEK 10 ********************************
-------------------------------------
set, check and delete cookie
-------------------------------------
1. set cookie: download git/login/page.tsx and paste into src/app/login/page.tsx
2. check and delete (logout) cookie: 
		download git/users/page.tsx and paste into src/app/users/page.tsx....identify the new additions
		
-----checklist-----
Cookie is set in:
src/app/login/page.tsx → document.cookie = "user=..."

Cookie is checked in:
src/app/users/page.tsx → document.cookie (inside useEffect)

-------------------------------------
Authentication flow
-------------------------------------
1. Login page sets cookie using document.cookie
2. Users page checks cookie before loading
3. If cookie not found → redirect to /login
4. If cookie exists → allow access

-------------------------------------
Logout functionality
-------------------------------------
1. Deletes cookie by setting expiry date in past
2. Redirects user to login page
3. Users page becomes protected again

------------------------------------
Test flow
------------------------------------
1. Open /users → should redirect
2. Login → cookie created
3. Access /users → allowed
4. Logout → blocked again
